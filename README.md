# Aplikasi Catatan (Notes App)

Aplikasi Catatan adalah aplikasi Android sederhana yang dibuat menggunakan Java dan Android Studio.
Aplikasi ini memungkinkan pengguna untuk menambah, mengedit, menghapus, dan melihat daftar catatan, serta mendukung multi-bahasa (Indonesia & Inggris).

# ✨ Fitur Utama

 Tambah Catatan

 Edit Catatan

 Hapus Catatan

 Daftar Catatan (RecyclerView)

 Menampilkan tanggal & waktu

 Hitung jumlah karakter secara realtime

 Multi Bahasa (Indonesia & English)

 Penyimpanan Lokal menggunakan Room Database

# 🛠️ Teknologi yang Digunakan

Bahasa Pemrograman: Java

IDE: Android Studio

Database: Room (SQLite)

UI: XML Layout + ConstraintLayout

Arsitektur: DAO (Data Access Object)

Komponen Android:

RecyclerView

FloatingActionButton

Activity

Intent
